# ЦСКА × Ростов Дон — Streamlit + DuckDB Dashboard

Интерактивное приложение на Streamlit для анализа истории матчей между **ЦСКА** и **Ростов Дон**. Проект работает с Excel-файлами, связывает матчи и статистику через `ID_match`, строит таблицы, рейтинги, графики и позволяет готовить проект к публикации на Streamlit Community Cloud.

https://cskarostovapp-xv962gmwqkm4ncixqwdury.streamlit.app/

## Основные возможности

- просмотр истории матчей ЦСКА — Ростов Дон;
- фильтрация матчей по сезону, турниру, победителю, арене, судьям и датам;
- карточка выбранного матча со счётом, командами, ареной, посещаемостью и судьями;
- гистограмма посещаемости по аренам;
- рейтинг пар судей по формуле: победа Ростова = `+1`, победа ЦСКА = `-1`, ничья = `0`;
- таблица игроков и официальных лиц;
- диаграмма роста игроков с переключением по амплуа;
- сводная статистика полевых игроков;
- сводная статистика вратарей;
- индивидуальная статистика игроков и голкиперов;
- топ-15 игроков по `гол + пас`;
- топ-10 игроков по `блок + перехват`;
- топ-10 игроков по среднему времени удалений;
- рейтинг вратарей по проценту отбитых бросков;
- вкладка DuckDB для проверки SQL-запросов;
- поддержка PDF-карт бросков в папке `Shoot_map` для скачивания.

## Файлы данных

### `data/Matches.xlsx`

Файл с матчами. Используется как основная таблица матчей.

Ключевая колонка:

```text
ID_match
```

Через неё матчи связываются со статистикой игроков и вратарей.

Примеры используемых колонок:

```text
ID_match
Date
Season
Tournament
Stage
Home_Team
Away_Team
Score
First_Half_Score
Number_of_Goals
Result
Referees
Attendance_Rate
Capacity
Arena
```

### `data/Players.xlsx`

Файл с составами игроков и официальными лицами.

Используемые листы:

```text
Лист1 — игроки
Лист2 — официальные лица
```

Примеры колонок игроков:

```text
Players
Team
Position
Citizenship
Height
Age
No
```

### `data/Result.xlsx`

Файл со статистикой матчей.

Используемые листы:

```text
A — индивидуальная статистика полевых игроков
B — индивидуальная статистика вратарей
AggregateStatisticsPlayers — агрегированная командная статистика игроков
AggregateStatisicsGoalkeepers / AggregateStatisticsGoalkeepers — агрегированная статистика голкиперов
```

Важно: в листах `A` и `B` должна быть колонка `Team`. Она показывает, за какую команду игрок или вратарь выступал именно в конкретном матче.

## Связь данных

Основная связь проекта:

```text
Matches.xlsx / ID_match
        ↓
Result.xlsx / A / ID_match
Result.xlsx / B / ID_match
Result.xlsx / AggregateStatisticsPlayers / ID_match
Result.xlsx / AggregateStatisticsGoalkeepers / ID_match
```

`ID_match` должен совпадать во всех таблицах.

## Streamlit-вкладки

### 1. Матчи

На вкладке отображаются:

- общая таблица матчей;
- фильтры по арене, судьям, победителю и периоду;
- количество матчей;
- победы ЦСКА;
- победы Ростова;
- общее количество голов;
- средняя посещаемость, округлённая до целых;
- гистограмма посещаемости по аренам;
- рейтинг пар судей;
- детализация выбранного матча;
- командная статистика по выбранному матчу.

Гистограмма посещаемости использует цвета:

```text
Ростов / Ростов-на-Дону — жёлтый
Москва / ЦСКА — красный
нейтральные арены — серый
```

Рейтинг судей считается так:

```text
победа Ростова = +1
победа ЦСКА = -1
ничья = 0
```

Результат сортируется от наиболее благоприятного значения для Ростова к наиболее благоприятному значению для ЦСКА.

### 2. Игроки

На вкладке отображаются:

- список игроков;
- фильтр по команде;
- фильтр по амплуа;
- поиск игрока;
- таблица официальных лиц;
- сводная статистика полевых игроков;
- сводная статистика вратарей;
- диаграмма роста игроков.

Диаграмма роста:

- строится по колонке `Height`;
- имеет переключатель по амплуа;
- поддерживает сортировку от меньшего роста к большему и от большего к меньшему;
- окрашивает столбцы в зависимости от амплуа;
- не показывает среднее значение на столбцах.

### 3. Статистика игроков

Вкладка использует индивидуальную статистику полевых игроков из листа `A` файла `Result.xlsx`.

Фильтры:

```text
Команда
Сезон
ID матча
```

На вкладке выводятся:

- топ-15 полевых игроков по сумме `гол + пас`;
- топ-10 игроков по сумме `блок + перехват`;
- топ-10 игроков по среднему времени удалений;
- таблица индивидуальных строк статистики.

Графики окрашиваются по командам:

```text
Ростов Дон — жёлто-чёрная гамма
ЦСКА — красно-синяя гамма
```

#### Гол + пас

Голы берутся из показателя `Goals`, где значение может быть записано в формате:

```text
голы/броски
```

Например:

```text
5/8
```

Для графика берётся число до слэша.

Пасы берутся из колонки:

```text
Assist
```

Итоговый показатель:

```text
Гол+пас = Голы + Пасы
```

На графике один столбец на игрока, а внутри столбца показатели расположены друг над другом.

#### Блок + перехват

Блоки берутся из защитного показателя блоков, перехваты — из колонки:

```text
Steal/Interception
```

Итоговый показатель:

```text
Блок+перехват = Блоки + Перехваты
```

#### Среднее время удалений

Используется колонка:

```text
2-minutes
```

Расчёт:

```text
Среднее время удалений за матч = количество удалений × 2 / количество матчей
```

Результат округляется до сотых.

### 4. Статистика голкиперов

Вкладка использует индивидуальную статистику вратарей из листа `B` файла `Result.xlsx`.

Фильтры:

```text
Команда
Сезон
ID матча
Минимальное количество матчей
```

Основной расчёт выполняется по колонке:

```text
total
```

Значение имеет формат:

```text
отбитые броски / всего бросков
```

Например:

```text
13/37
```

Для каждого вратаря суммируются все отбитые броски и все броски по матчам:

```text
9/27 + 4/10 = 13/37
```

Процент сейвов считается заново:

```text
% сейвов = отбитые броски / всего бросков × 100
```

Процент округляется до сотых процента.

### 5. Карта бросков

PDF-карты бросков должны лежать в папке:

```text
Shoot_map/
```

Формат названия файла:

```text
Shoot ID.pdf
```

где `ID` — номер матча из колонки `ID_match`.

Примеры:

```text
Shoot_map/Shoot 1.pdf
Shoot_map/Shoot 2.pdf
Shoot_map/Shoot 15.pdf
```

На вкладке карты бросков PDF не отображается внутри приложения. Доступна только возможность выбрать файл и скачать его.

### 6. DuckDB

Вкладка предназначена для проверки связей и выполнения безопасных SQL-запросов.

Доступные таблицы:

```text
matches
players
officials
player_stats
goalkeeper_stats
aggregate_players
aggregate_goalkeepers
player_stats_enriched
goalkeeper_stats_enriched
```

Разрешены только `SELECT`-запросы.

## Сводная статистика игроков

Сводная таблица полевых игроков исключает вратарей.

Показатели вида:

```text
3/5
2/4
```

суммируются отдельно до и после слэша:

```text
3/5 + 2/4 = 5/9
```

Группировка выполняется по:

```text
Игрок
Команда
```

Это важно, если игрок в разные периоды выступал за разные команды.

## Сводная статистика вратарей

Сводная таблица вратарей использует только вратарскую статистику.

Полевые игроки в неё не попадают.

Показатели вида:

```text
сейвы/броски
```

суммируются отдельно до и после слэша.

Проценты пересчитываются от итоговой дроби, а не усредняются по матчам.

## Установка локально

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Windows:

```bash
.venv\Scripts\activate
```

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash

```

3. Замените нужный файл:

## Обновление карт бросков

Чтобы добавить новую карту бросков:

1. Откройте папку `Shoot_map`.
2. Добавьте PDF с названием:

```text
Shoot ID.pdf
```

Например:

```text

```

3. Убедитесь, что `23` есть в `Matches.xlsx` в колонке `ID_match`.
4. Сделайте commit в GitHub.
5. Перезапустите приложение в Streamlit Cloud.

## Частые ошибки

### Не найдены Excel-файлы

Проверьте, что файлы лежат строго в папке:

```text
data/
```

И называются:

```text
Matches.xlsx
Players.xlsx
Result.xlsx
```

Названия чувствительны к регистру.

### Нет модуля `openpyxl`

Добавьте в `requirements.txt`:

```text
openpyxl>=3.1
```

### Не работает связь статистики с матчами

Проверьте колонку:

```text
ID_match
```

Она должна быть и в `Matches.xlsx`, и в листах статистики файла `Result.xlsx`.

### Команда игрока отображается неверно

Проверьте колонку `Team` в листах `A` и `B` файла `Result.xlsx`.

Именно она используется как источник команды игрока или вратаря на момент конкретного матча.

### Карта бросков не находится

Проверьте формат названия PDF:

```text
Shoot ID.pdf
```

Например:

```text
Shoot 7.pdf
```

а не:

```text
ID_match_7.pdf
match_7.pdf
```

## Логика проекта

Главная идея проекта — не хранить отдельную базу данных, а читать Excel-файлы из GitHub-репозитория, подготавливать таблицы в Pandas и использовать DuckDB для SQL-связей и аналитики.

Основной ключ данных:

```text
ID_match
```

Он связывает матчи, игроков, вратарей, командную статистику и карты бросков.
